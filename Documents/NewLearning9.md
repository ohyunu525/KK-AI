# NewLearning9: 전하 5개, 순서에 무관한 sign-only 학습

## 실행

프로젝트 루트의 PowerShell에서 실행합니다.

```powershell
# 5개 전하 데이터를 별도로 생성하고 짧은 검사를 실행
& .\.venv\Scripts\python.exe Codes/NewLearning9.py --generate-data --smoke-only

# 기본 실험: seed 3개 × G05 비율 6개, 최대 300 epoch (G00는 seed마다 한 번)
& .\.venv\Scripts\python.exe Codes/NewLearning9.py

# 한 조건만 학습하는 예시
& .\.venv\Scripts\python.exe Codes/NewLearning9.py --seeds 41 --fractions 1 --epochs 100

# 회귀 테스트
& .\.venv\Scripts\python.exe -m unittest discover -s Codes -p 'test_*.py' -v
```

`--generate-data`는 해당 경로에 파일이 없을 때만 생성합니다. 기본값은 10,000개 샘플, 32개 후보 G05 센서입니다. `--samples`, `--g05-points`, `--data-seed`로 조절할 수 있습니다. 기존 파일이 있으면 재사용하므로 다른 데이터가 필요하면 `--data`로 새 경로를 지정합니다.

생성기만 사용하는 경우도 지원합니다. 생성기의 기존 기본값인 전하 2개는 유지됩니다.

```powershell
& .\.venv\Scripts\python.exe Codes/generate_charge_dataset.py --charges 5
```

## sign-only의 의미

이 코드의 sign-only는 기존 `ModelExperiment.py`의 입력 경로 구분을 따릅니다. 전하량을 ±1로 고정하는 뜻이 아닙니다.

| 예측 항목 | 사용하는 입력 |
| --- | --- |
| 다섯 전하의 3차원 위치 | G00만 |
| 다섯 전하의 크기 `|q|` | G00만 |
| 다섯 전하의 상대 부호 | G00만 |
| 전체 부호 | 마스킹된 G05만 |

두 가지가 별도로 학습됩니다. G05 입력을 바꾸어도 구조 출력은 같고, G05 전체 부호 손실의 기울기가 구조 파라미터에 전달되지 않습니다. 공동 기울기 클리핑이나 전체 손실 기반 학습률 조절도 적용하지 않습니다. 이런 연산은 독립적인 두 분기를 다시 연결할 수 있기 때문입니다.

같은 실행 안에서는 **G00 구조 분기를 seed마다 한 번만 학습**합니다. 첫 번째 G05 비율에서 얻은 최적 구조 체크포인트를 나머지 비율에 재사용하고, 이후에는 G00 순전파·역전파 없이 G05 분기만 학습합니다. G05 초기화와 데이터 셔플 seed는 기존 방식과 같습니다. 재사용 전에는 seed, 학습 설정, 정규화, 데이터·분할 메타데이터의 일치 여부를 확인합니다.

## 순서 문제를 해결한 방법

각 출력 슬롯은 `(위치, 크기, 상대 부호)`를 함께 나타냅니다. 정답은 `[N,20]` 또는 `[N,5,4]`이고, 다섯 `(x,y,z,q)` 묶음은 어느 순서로 저장해도 됩니다. 출력에는 고정된 전하 번호 의미가 없습니다.

매 학습 배치에서 가능한 **5! = 120가지 일대일 대응을 모두 비교**합니다. 정규화된 위치 MSE, 크기 MSE, 상대 부호 비용의 합이 최소가 되는 대응을 선택하고, 그 대응으로 손실을 역전파합니다. 정답 하나가 여러 예측에 중복 대응되는 최근접점 방식은 사용하지 않습니다.

전하가 정확히 5개이므로 120가지 비교를 PyTorch 장치 안에서 처리할 수 있습니다. Hungarian 매칭과 같은 최소 비용 할당 문제를 정확히 풀며, SciPy나 CPU로 데이터를 이동하는 과정이 필요하지 않습니다. 전하 수가 크게 늘면 순열 열거 대신 다항 시간 할당 알고리즘을 검토해야 합니다.

위치 정규화는 훈련 데이터의 모든 전하를 모아 **축별 공통 평균·표준편차 3개씩**을 구합니다. 전하 번호마다 다른 정규화를 적용하지 않습니다. 평가에도 같은 구조 비용의 일대일 대응을 사용하며, G05나 예측 전체 부호는 대응 선택에 관여하지 않습니다. 위치 지표는 이 공동 대응 아래의 오차이며, 위치만 따로 최소화한 지표와는 다를 수 있습니다.

집합 예측의 일대일 매칭 손실 참고: [End-to-End Object Detection with Transformers](https://arxiv.org/abs/2005.12872).

## 전하 번호에 의존하지 않는 부호 표현

전하가 5개이고 모두 0이 아니면 다음과 같이 정의할 수 있습니다.

```text
s_i = sign(q_i)
g   = s_1 × s_2 × s_3 × s_4 × s_5
r_i = s_i × g
q_i = |q_i| × r_i × g
```

`g`는 전하 순서와 무관합니다. 모든 `q`의 부호를 뒤집으면 `g`만 뒤집히고 `r_i`는 그대로입니다. 또 `r_1 × … × r_5 = +1`입니다. 따라서 첫 번째 예측 슬롯을 전체 부호의 기준으로 삼을 필요가 없습니다.

상대 부호 학습에는 이 조건을 만족하는 16개 패턴의 조건부 음의 로그 우도를 사용합니다. 추론도 그중 확률이 가장 높은 패턴을 선택합니다. 확률이 정확히 같으면 최적 패턴 하나를 선택합니다. 매칭의 부호 비용은 이 손실과 정답 순열에 무관한 상수만큼 차이나므로 실제 구조 손실의 최소 대응을 정확히 찾습니다.

G05 분기는 측정 전위 `V`를 모두 반전하면 전체 부호 logit도 정확히 반전하도록 구성했습니다. 관측이 없는 샘플의 logit은 0이며, 전체 부호를 아는 것으로 취급하지 않습니다.

## 데이터와 결과

| 항목 | 기본 경로 |
| --- | --- |
| 전하 5개 데이터 | `Models/charge_dataset_5charges_v9.npz` |
| 조건별 최적 분기·합성 체크포인트, epoch 이력 | `Models/new_learning9/run_*/seed_*_g05_*/` |
| G05 비율별 검증 손실 최적 모델 | `Models/new_learning9/run_*/best_g05_*.pt` |
| 정규화 | `Models/new_learning9/run_*/normalization.npz` |
| 실행별 지표·seed 평균과 표준편차 | `Results/new_learning9/run_*/runs.csv`, `summary.csv` |
| 비교 그래프·실험 정의 | `Results/new_learning9/run_*/summary.png`, `protocol.json` |

학습을 실행할 때마다 `run_<시간>_<고유값>` 폴더를 새로 만듭니다. 체크포인트와 결과 폴더는 같은 실행 ID를 사용하며, 실제 저장 경로는 학습 시작과 종료 시 출력합니다. `--checkpoint-dir`와 `--results-dir`는 이 실행 폴더를 담는 상위 경로입니다. 일부 seed나 G05 비율만 재실행해도 이전 실행의 CSV, 정규화, 프로토콜, 체크포인트를 덮어쓰지 않습니다. 예전 폴더 구조로 저장한 파일도 그대로 보존합니다. 실행 간 결과를 자동 병합하거나 학습을 이어서 진행하지는 않습니다.

구조를 재사용한 체크포인트에는 원본 `best_structure.pt`의 경로를 `structure_source`로 기록합니다. 해당 조건의 `history.csv`에는 실제 학습한 G05 손실만 기록하며, 구조의 학습 이력은 원본 체크포인트 폴더에 남습니다. 합성 체크포인트는 모든 모델 파라미터를 포함하므로 추론 시 원본 구조 파일을 따로 읽을 필요가 없습니다. `train_model()`을 직접 호출할 때도 같은 seed·비율의 저장 폴더가 이미 있으면 덮어쓰지 않고 `FileExistsError`를 발생시킵니다.

데이터 로더는 전하가 정확히 5개인지, `G00=V²`와 `G05=V`가 일치하는지 검사합니다. 관측면 반사 대칭을 제거하기 위해 `z>0`, 부호 정의를 위해 `q≠0`을 요구합니다. 센서 후보 위치는 샘플마다 같아야 하며, 같은 후보 목록의 앞부분을 사용하는 방식으로 관측 비율을 늘립니다. **G05 100%는 저장된 후보 센서 전부**를 뜻합니다.

훈련/검증/시험은 고정 seed의 80/10/10 분할이고, 정규화 통계는 훈련 분할에서만 계산합니다. 구조 분기는 위치·크기·상대 부호를 함께 저장하여 슬롯 간 대응을 유지하고, 독립적인 전체 부호 분기와 각각 최적 검증 epoch에서 합성합니다. 시험 지표는 모델 선택에 사용하지 않습니다.

G05가 없는 샘플은 절대 부호를 식별할 수 없습니다. 이 경우 전체·절대 부호 정확도는 `N/A`이며, 전하 MAE는 다섯 전하를 **모두 함께** 반전한 두 경우 중 작은 값으로 평가합니다. 개별 전하마다 부호를 임의로 바꾸어 오차를 줄이지 않습니다.

기존 2개 전하 데이터·학습 코드·체크포인트는 덮어쓰지 않습니다. 기존 `visualize_3d.py`의 2개 전하 체크포인트 로더는 이 새 모델을 지원하지 않습니다. Python 추론에는 `NewLearning9.load_trained_model()`과 `reconstruct_charges()`를 사용할 수 있습니다. 위치는 저장된 평균·표준편차로 역정규화하고 전하에는 `charge_scale`을 곱해야 합니다.

`--smoke-only`는 형상, 순서 불변 손실, 분기 기울기, 한 배치 최적화 단계를 검사합니다. 전체 학습 결과나 예측 정확도를 보장하는 검사는 아닙니다. 5개 전하 역문제의 정확도는 실제 학습 후 시험 데이터로 확인해야 합니다.
