## 확인된 정상 동작

- ModelExperiment 계열은 현재 dataset SHA-256, 저장 split, seed 42 재생성 split, 세 split hash가 모두 정확히 일치했습니다.
- target 해석은 `[x1,y1,z1,q1,x2,y2,z2,q2] → position=[x1,y1,z1,x2,y2,z2], charge=[q1,q2]`로 정확합니다.
- 입력 정규화와 position/charge 역정규화는 기존 평가와 같고, raw target 복원 assertion도 있습니다.
- G00/G05 preprocessing과 nested-prefix mask는 `physics.prepare_dataset()`을 그대로 재사용합니다.
- `model.eval()`, `torch.no_grad()`, device 이동, `map_location` 처리는 올바릅니다.
- G00 heatmap과 G05 위치는 모두 선택된 `sample.dataset_index`의 raw dataset 값을 사용하며 x/y indexing 방향도 맞습니다.
- 축은 관측 grid와 예측치를 모두 포함하고 `set_box_aspect`로 물리적 비율을 유지합니다. marker의 true=`o`, predicted=`^` 대응과 q1/q2 label도 맞습니다.
- best/median/worst 기준은 각 샘플의 `0.5 × (charge1 3D error + charge2 3D error)`로 계산되어 기존 aggregate metric과 일치합니다.

Permutation에 대해서는 두 코드 모두 matching을 하지 않고 lexicographically ordered slot을 identity 대응합니다. 따라서 기존 평가와는 일치하지만 “matching 후 error”라는 표현은 문자 그대로는 맞지 않습니다. 연구 metric을 unordered-set reconstruction으로 정의하려는 경우에는 direct/swapped assignment 중 작은 값을 선택하도록 기존 evaluation과 시각화 모두 수정하고 결과를 재산출해야 합니다.

최종 판정은 **수정 후 사용 가능**입니다. 제한적으로는 완료된 ModelExperiment의 `best.pt`, G05>0, median sample을 사용하고 선택 방식을 PPT에 명시하면 현재 수치 경로는 일관됩니다. 일반 연구·발표 도구로 쓰려면 위 P1 문제를 먼저 해결해야 합니다.
